# Changelog

## [1.1.0] - 2026-07-06

### Added
- GitHub Actions CI/CD pipeline with build, test, lint, format checks
- Makefile for build automation and release workflow
- Release automation with artifact uploads

### Changed
- Refined cyberpunk UI theme with improved colors and visual hierarchy
- Enhanced tab bar with better spacing and active tab highlighting
- Improved URL bar with lock icon for HTTPS connections
- Redesigned status bar with cleaner layout and section separators
- Updated overlay designs with improved borders and spacing
- Enhanced HTML renderer with better paragraph flow, inline links, and typography
- Improved table rendering with column alignment and visual separators
- Better code block presentation with background contrast
- Enhanced list rendering with consistent indentation
- Upgraded reader mode display with refined typography
- Updated welcome screen with cleaner layout

### Fixed
- Various rendering edge cases in HTML-to-TUI conversion
- Improved content extraction fallback handling

## [1.0.0] - Initial Release

- Terminal browser with tabbed browsing
- HTML rendering with cyberpunk theme
- Reader mode for article extraction
- Ad blocking, bookmarks, history
- Search engine integration
- Proxy support
- Privacy mode
- Headless Chromium for JS-rendered pages
